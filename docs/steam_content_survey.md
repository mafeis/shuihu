# 《星命水浒》Steam 内容调查与合规填写稿

更新日期：2026-10-19

本文件用于填写 Steamworks 后台的商店内容调查、年龄分级问卷与生成式 AI 披露。最终答案必须由发行主体在提交前逐项复核，不能替代 Valve 审核或法律意见。

## 1. 产品与版本边界

- 游戏类型：单机、回合制角色扮演、队伍构筑、轻量 Roguelite。
- 玩家数量：单人。
- 在线账号：游戏本体不要求注册。
- 广告、内购、加密货币或博彩：无。
- 开发者遥测、行为分析或远程崩溃上报：无。
- Steam 集成：Achievements、Stats、Rich Presence、Overlay、Cloud 与标准手柄输入。
- 游戏运行时不调用生成式 AI，不下载模型，不向 ComfyUI 或开发者服务器发送玩家数据。

## 2. 暴力与成人内容

建议在内容调查中按以下事实填写：

| 项目 | 是否存在 | 说明 |
| --- | --- | --- |
| 冷兵器战斗 | 是 | 回合制角色攻击、格挡、流血、破甲和眩晕表现。 |
| 非写实血液 | 是 | 战斗界面使用风格化红色状态提示和受击反馈，无肢解。 |
| 写实肢解 | 否 | 无断肢、内脏或尸体破坏特写。 |
| 针对性暴力 | 是 | 剧情涉及冤案、押解、处刑场威胁和官府压迫。 |
| 性内容 | 否 | 无裸露、性行为或性暗示内容。 |
| 毒品或吸烟 | 否 | 剧情可提及酒馆饮酒，不鼓励现实酒精消费。 |
| 粗俗语言 | 否 | 无现代脏话或仇恨言论。 |
| 赌博 | 否 | 游戏内资源与演武奖励不涉及真实货币或随机付费。 |
| 恐怖惊吓 | 轻微 | 雪夜、囚禁和法场氛围可能有压迫感，无追逐惊吓或血腥演出。 |

商店页需要保留现有内容说明：

> 游戏包含冷兵器战斗、风格化流血、囚禁、冤案和权力压迫等主题，不含写实肢解或性内容。

## 3. 年龄分级建议

不建议项目自行宣布最终分级。提交 IARC 问卷时可依据以下事实作答：

- 暴力：风格化、回合制、冷兵器；存在血液状态效果，但无肢解。
- 恐怖：场景氛围和剧情威胁，无强烈惊吓。
- 语言：无粗俗语言。
- 性、毒品、赌博：无。
- 在线互动、用户生成内容、位置共享、数字商品：无。

预计进入“青少年/12+”附近区间，但最终以发行地区和 IARC 返回结果为准。

## 4. 生成式 AI 披露

### 是否存在预生成 AI 内容

**是。**

游戏包含开发阶段通过 ComfyUI 管线预生成的角色主视觉、四视图、透明立绘、场景、敌人图、UI 图标母版、标题视频、配乐与战斗音效。玩家运行时不会生成新内容。

### 是否存在实时生成内容

**否。**

- 运行包不包含 ComfyUI、模型权重或生成端点。
- 游戏不向玩家询问提示词。
- 游戏不把存档、设备信息或个人数据发送给生成模型。
- 所有生成资产在构建时固化，并记录模型、工作流、种子和 SHA-256。

### 使用的生成工具

- 图像：ComfyUI、Qwen Image 2.1、Qwen Image Edit。
- 视频：ComfyUI、MiniMax H3。
- 音频：ComfyUI、YuE2 3B；十枚战斗一次性音效另经确定性瞬态合成、裁切、母带与峰值限制处理。
- SeedVR2：仅作为后续高清资产候选工具登记，当前运行时资产清单未证明实际使用。

### 人工审核与后期

- 人工筛选提示词、种子和最终候选图。
- 人工检查人物身份、武器、手部、服饰、透明边缘、缩放和历史风格。
- 图像导出后进行规范命名、尺寸适配、透明通道检查与打包。
- 音乐经过剪辑、循环闭合、两遍响度母带、真峰值检查与 MP3 编码。
- 战斗音效逐枚检查语义、起音、尾音、响度与真峰值，并在实际战斗事件中完成回放测试。
- 游戏代码、剧情文本、UI 布局、规则、数值与最终组合由人工完成。

完整机器可读说明见 [steam_ai_disclosure.json](../store/steam_ai_disclosure.json)，资产追溯见 [manifest.json](../assets/manifest.json)。

## 5. 第三方模型与工具授权

提交 Steam 前，发行主体必须保存并核对以下材料：

- Qwen Image 2.1 与 Qwen Image Edit 的模型许可证及商用条款。
- MiniMax H3 模型、VAE、LoRA 与相关自定义节点的商用条款。
- YuE2 3B 模型及 ComfyUI 自定义音乐节点的商用条款。
- 实际使用的训练数据附加限制、署名要求与再分发限制。
- ComfyUI 本体及每个第三方自定义节点的许可证。
- 若使用 SeedVR2 或其他放大模型，其模型许可证和最终资产使用范围。

当前仓库可以证明资产来源与生产流程，但不能替代对上述许可证的最终法律核验。

## 6. 隐私与客服信息

Steam 商店和游戏内支持入口正式发布前需要填写：

- 发行主体法定名称。
- 支持邮箱与支持网页。
- 营业地址或数据控制者地址。
- 适用法律与争议解决地区。
- 隐私说明生效日期和联系渠道。

当前本地日志不会自动上传。若未来加入远程崩溃上报、账号、分析 SDK 或在线服务，必须重新进行内容调查和隐私复核。
