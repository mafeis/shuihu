# 星命水浒：风雪山神庙 1.0.1

1.0.1 是面向公开分享的体验更新，集中改善战斗反馈与配乐、人物轮廓、名册与装备分页、各处滚动和窄屏布局，并重做梁山营寨的建造、生产、库存与扩建循环。本次同时补齐托管战斗的目标选择、治疗与辅助循环修复，以及 macOS 辅助进程签名。开场动画和 UI 点击动效仍分别由 GitHub issue #19、#22 跟踪，本次会把它们明确列为后续工作。

## 战斗与人物表现

- 战斗增加动作、命中、暴击、闪避与治疗反馈，战报不再只显示血条变化。
- 补全战斗开始、斩击、重击、投掷、格挡、闪避、治疗、连击和胜负音效；切换章节时场景配乐会随剧情与首领战正确切换。
- 修复清风寨战斗音乐路由，普通章回不再错误复用标题曲。
- 为人物增加适应暗景的清晰轮廓光，剧情立绘、战斗与人物卡片在深色背景中更容易辨认。
- 战卷中的 27 枚评鉴、人物成长和敌方压制仍与九回主线衔接，同时补充回归覆盖，避免数值变化破坏阵容策略。
- 自动战法会优先治疗生命最低的受伤队友；全队满血时不再反复释放纯护御，而是选择有效伤害，保留会补充义气的辅助大招。
- 修复前排或后排目标阵位已空时技能没有合法目标的问题，会自动回退到仍存活的敌人；新增重复护御与连续辅助的回归用例。
- 新增“青州霹雳”“笔改灯市”等招募链回归，验证三阵队伍能够继续推进章回、招募与战后结算。

## 名册、装备与界面

- 好汉名册支持按路数筛选与分页，每页 16 人，可快速比较路数并进入编成。
- 整理可行囊分为兵刃、护甲和随身物，支持装备分类、武将路数筛选与每页五件分页。
- 修复推荐桌面与移动分辨率下的页面横向滚动条、内容裁切和底部导航遮挡，主要界面在 1920、1440、1280、1024、768 与 390px 宽度下均可正常操作。
- 调整响应式布局中的卡片、按钮、分页和文字尺寸，长名称与动态数值不会撑破容器。

## 梁山营寨与经营

- 营寨改为真实格点布局：聚义厅、演武场、农田、矿场和林地占 2 × 2 格，星台、水产、石磨和厨房占 1 × 1 格，建筑不会互相遮挡或越出营图。
- 建筑随累计胜场开放，并可用铜钱建造；营图会显示建筑占地、等级、解锁条件、价格与当前库存。
- 农田、矿场、林地和水产可以采收小麦、铁矿、木材和鲜鱼，产量随建筑等级提高。
- 新增生产链：石磨将 2 份小麦加工为 1 份面粉，厨房将 1 份面粉加工为 2 个馒头。
- 营区随战功逐步开放，并可消耗铜钱、木材和铁矿继续扩建：5 胜后可扩建至 6 × 5，10 胜后可扩建至 8 × 5。
- 营寨库存与营区扩建状态会写入存档；更新旧存档时会保留已建建筑、库存、已开放营区与好汉进度。

## 存档与修复

- 存档版本升级至 27，兼容旧版招募、演武、装备、营寨与结局归档数据。
- 修复浏览器全流程测试的装备夹具，使装备列表能够实际覆盖多页并验证翻页；同时保留快速专项回归入口。
- 新增第七回“笔改灯市”招募战回归：1 级起步、随章回自然升级的三阵队伍分别以均衡、破阵/追残轮换与守势战法在“说书人”难度完成战斗，防止后续数值调整让招募流程断档。
- 修复 macOS 打包时被误判为“无需签名”的配置；1.0.1 使用显式 ad-hoc 签名、Hardened Runtime 与分层权限配置，确保应用与 Electron 辅助进程能够正常启动。
- 补齐全套 Electron Helper 与 Framework 的签名、主程序及继承权限差异，并在打包后执行 `codesign --verify --deep --strict`；macOS 最低系统版本固定为 13.0。
- Windows x64 与 Windows ARM64 均在同一版本中提供 NSIS 安装包和免安装 ZIP，供不同架构的机器选择。

## 版本说明

- 本次提供 Apple 芯片 macOS 13.0+ 的 DMG 与 ZIP，以及 Windows x64 / ARM64 安装包与免安装包。
- macOS 测试包使用 ad-hoc 签名，没有 Apple Developer ID 签名与公证，Gatekeeper 会拦截首次打开。可在 Finder 中右键“星命水浒”并选择“打开”，或者在终端执行：

  ```bash
  xattr -dr com.apple.quarantine "/Applications/星命水浒.app"
  ```

- Windows 安装包没有 Authenticode 证书，SmartScreen 可能提示未知发布者；请只从本仓库发行页下载并核对 SHA-256。
- 分享前请核对两个 macOS 包、四个 Windows 包与本地分享 ZIP 的 SHA-256 与发行页一致。
