# 《星命水浒：风雪山神庙》完整游戏策划案

版本：1.0.2
类型：单机群像回合制 RPG / 队伍构筑 / 轻度 Roguelite 挑战  
平台：浏览器优先，可安装 PWA；桌面版可由 Electron 封装  
核心时长：首轮 10 至 16 小时，完整收集与挑战 30 小时以上  
玩家规模：单人  
商业模式：一次购买或完整版买断，无抽卡、体力、广告和强制签到

## 1. 产品定位

### 1.1 一句话介绍

玩家从林冲的风雪冤案出发，在九回北宋乱世战役中结义四十位好汉，用三人阵位、四路克制、兄弟契与星命合击打出自己的梁山道路，并在聚义、招安与归隐之间作出最终选择。

### 1.2 核心幻想

- 我不是在收集无名小兵，而是在认识一群有欲望、有旧债、有选择的人物。
- 我不是在等数值碾压，而是在有限阵位里组合路数、义气、契文与出手顺序。
- 我不是按唯一答案通关，而是在主线、人物列传、演武构筑和终局路线之间决定先追什么。
- 自动战斗可以节省重复操作，但手动指挥能看见更清楚的破阵收益。

### 1.3 目标玩家

- 喜欢《宝可梦》式队伍收集与克制，但更偏好成人角色、阵位和叙事选择的玩家。
- 喜欢《水浒传》群像、公版历史题材和北宋视觉氛围的玩家。
- 喜欢 20 至 40 分钟一段完整推进、可随时中断并继续的浏览器玩家。
- 喜欢自动战斗、倍速与无尽挑战，同时不接受每日任务和付费压力的玩家。

### 1.4 设计边界

- 借用“收集伙伴、属性克制、持续养成、挑战强敌”的玩法骨架，不复制任何受保护的宝可梦角色、名称、素材、数值表或表现。
- 好汉不是可随意丢弃的宠物。人物拥有独立列传、招贤条件和永久成长，收集本身就是叙事。
- 不做联网账号、排行榜强制联网、抽卡、体力锁、付费加速或广告复活。
- 不宣称当前版本拥有原著一百零八将。发行内容明确为四十位可结义好汉。

## 2. 玩家体验目标

### 2.1 每 30 秒要有反馈

- 一次有效出招会给出伤害、护御、破甲、流血、义气或路数蓄力的可见结果。
- 战斗日志、角色动作、数字跳字和音效同步，避免只改血条。
- 自动战斗仍会显示战报与关键状态，不把过程压成黑箱。

### 2.2 每 5 分钟要有选择

- 战前选择三人阵位、兄弟契和装备。
- 战中决定先破前阵、处理治疗敌人、积攒合击还是保留义技。
- 战后选择人物故事、营寨建设、招贤、装备分配或演武目标。

### 2.3 每 30 分钟要有里程碑

- 完成一段章回剧情或一场首领战。
- 解锁一名好汉、一件唯一装备、一段列传或一项永久战功。
- 发现一条新的命途、兄弟契、阵谱、官军军势或演武构筑。

### 2.4 长期留存依靠内容，不依靠惩罚

- 主线之后仍可追四十场群英列传、二十八帖聚义招贤、无尽演武、星劫、周令和二周目。
- 不要求每日登录。每周固定牌池只提供新的策略题面，不扣除错过的资源。
- 暂时离开游戏不会损失队伍、关卡奖励或已解锁档案。

## 3. 核心循环

### 3.1 短循环：一场战斗

1. 读取敌阵、路数、首领阶段和特殊规则。
2. 选择普攻、技能、义技、合击或自动托管。
3. 形成三种不同路数的连续行动，蓄满星命。
4. 在合适窗口发动全队合击，处理护势、残血或首领阶段。
5. 获得资源、战报、评鉴目标和人物成长。

### 3.2 中循环：一回战役

1. 在江湖地图选择章回或人物故事。
2. 阅读冲突，作出至少一次有后果的剧情选择。
3. 获得对应战术，进入战斗并完成评鉴目标。
4. 收获铜钱、历练、装备、好汉和档案。
5. 返回营寨、名册、异闻或演武，决定下一步。

### 3.3 长循环：一条梁山道路

1. 推进九回主线并逐步解锁二十八帖招贤。
2. 用四十位好汉组成不同三阵，发现兄弟契与星命合击。
3. 完成一百二十段异闻和四十场列传，积累永久掌握。
4. 在演武、周令与星劫中检验构筑并冲击更高纪录。
5. 在聚义、招安、归隐中选择结局。
6. 二周目继承档案与设置，继续补齐命途、战功、评鉴和构筑图鉴。

## 4. 战斗系统

### 4.1 基础阵位

- 我方上阵三人，分为前阵、中阵与后阵。
- 前阵更常承受近战压力，中阵平衡输出与支援，后阵适合远射、谋略和治疗。
- 角色技能可以要求自身位于特定阵位，或改变敌人的目标选择。
- 自动战斗必须识别阵位职责，不能只选择面板最高伤害。

### 4.2 四路克制

| 路数 | 战场职责 | 典型效果 |
| --- | --- | --- |
| 刚猛 | 正面破阵、单体压制 | 破甲、追击、高额直接伤害 |
| 灵巧 | 连击、闪避、收割 | 身法、追加攻击、残血处决 |
| 韬略 | 群攻、控制、气脉 | 破势、状态延展、义气获取 |
| 守御 | 护阵、反击、援护 | 护御、减伤、反击、治疗 |

克制关系必须在战前和出招预览中可读。玩家不靠背隐藏表，而靠路数图标和提示判断。

### 4.3 行动资源

- 生命：归零后退出战斗；全队倒下则战败。
- 护御：优先吸收伤害，强化守势交换。
- 义气：通过行动、受击、契文与角色能力积累，用于义技。
- 星命：三种不同路数依次行动后蓄满，在下次我方行动窗口发动合击。
- 状态：破甲、流血、破势、鼓舞、护援、锁阵、封穴等。
- 首领阶段：生命阈值触发新技能或规则，战报必须说明变化。

### 4.4 星命合击

- 队伍中三种不同路数组成一种合击阵式，共四种组合。
- 蓄满后显示明确按钮，手动玩家可在关键回合决定释放时机。
- 合击具有全队收益，不只是一段更高伤害动画。
- 首次发现会入谱并给予永久档案奖励，重复使用仍保留战术价值。

### 4.5 自动战斗与倍速

- 均衡：综合治疗、护御、路数蓄力和残血收益。
- 破阵：优先处理高护势、前阵和可破甲目标。
- 守势：提前治疗和补护，等待安全窗口。
- 追残：集火低生命与可斩杀目标，优先暴击和单体收割。
- 速度：`1x / 2x / 4x`，影响结算、敌方行动和自动出招节奏。
- 任何战斗都能一键从自动切回手动，避免托管剥夺关键合击。
- 键盘 `A` 切换自动，`T` 轮换战法，`1 / 2 / 4` 改速度，`C` 发动合击。

### 4.6 可读性要求

- 所有状态使用图标、名称和短说明，不只靠颜色。
- 角色立绘、敌人、场景与 UI 资产必须等比缩放，不使用破坏比例的强制填充。
- 四十张好汉运行时立绘统一采用 `896×1024` RGBA 画布、底部 12px 安全线和同一 Alpha 边界规范；标题缩略图统一采用 `320×366`。
- 列表头像使用轻量透明缩略图，剧情与战斗大图保持原始素材分辨率。
- 关键按钮有键盘焦点、触屏尺寸和悬停说明。

## 5. 队伍构筑

### 5.1 好汉结构

每位好汉包含：

- 身份、绰号、星号、路数、阵位偏好和人物简介。
- 普通招式、技能、义技与被动。
- 等级、永久星命试炼与两套终局命途。
- 三段个人异闻、一段群英列传、专属战意与唯一奖励。
- 专属装备或列传装备，以及可被兄弟契放大的队伍职责。

### 5.2 兄弟契

- 共三十八组，包含双人契与三人契。
- 阵容同时上阵指定好汉即可激活，不要求抽到重复角色。
- 契文改变开局义气、护援、反击、追击、闪避、回血、破甲或状态延展。
- 首次发现入谱并给予一次性资源；之后仍由实际战斗规则持续生效。

### 5.3 命途

- 每名好汉有两个终局方向，完成永久试炼后解锁。
- 命途可自由切换，不用付费洗点。
- 一条更强调个人绝技，另一条更强调队伍协同或生存。
- 命途让同一个角色能适配不同的首领、演武规则和兄弟契。

### 5.4 装备

- 124 件装备覆盖武器、护甲与信物。
- 列传和招贤奖励包含唯一装备，不允许重复复制。
- 装备提供基础属性与构筑偏向，但不应完全盖过路数、阵位和操作。
- 自动装备可以推荐，但玩家始终能按阵容需求手动分配。

## 6. 战役与叙事

### 6.1 九回结构

1. 黄河夜渡：逃离封锁，建立三人队伍。
2. 东京雪夜：看见权力中心如何制造冤案。
3. 野猪林伏杀：在追杀与互救中确认同袍关系。
4. 沧州药火：处理牢城、药火与地方权力。
5. 清风寨月箭：让山寨、官军和个人选择发生冲突。
6. 江州劫法场：以公开处刑把私仇推向群体反抗。
7. 祝家庄雪夜：以盘陀路和乡土同盟考验梁山。
8. 大名府灯夜：把节庆表象与军事行动叠在一起。
9. 水泊聚义：将个人生存问题提升为梁山路线选择。

### 6.2 剧情选择

- 每回至少一次选择，并映射为一种可玩战术。
- 选择不只改一句台词，还会记录价值倾向、影响战斗开局或后续资源。
- 玩家可以在路线汇总中看见当前梁山更接近聚义、招安还是归隐。
- 三结局不按一个“正确值”判定，而看多条价值线与终局明确选择。

### 6.3 人物内容

- 28 场聚义招贤：独立剧情、取舍、专属战意、唯一装备。
- 120 段异闻：每名好汉三段逐步解锁的个人故事。
- 40 场群英列传：每个角色的终章规则战、叙事回报与永久档案。
- 星命路标按当前存档推荐下一步，避免玩家在大量内容前失去方向。

## 7. 养成与营寨

### 7.1 资源

- 铜钱：营寨建设、基础整备和长期经营。
- 历练：角色等级与阶段成长。
- 军功：演武挑战和周令评价。
- 档案：兄弟契、合击、命途、列传、军势和构筑图鉴。

### 7.2 营寨设施

- 设施升级提供稳定、可理解的长期收益。
- 升级成本公开，不设置随机失败或付费缩短。
- 休息可恢复队伍状态，成本和收益在按钮前明示。
- 二周目保留已完成的永久档案，不要求重复刷基础建设。

### 7.3 难度

- 说书人：敌方伤害降低，适合剧情玩家。
- 江湖客：标准攻防与资源收益。
- 演义录：敌方伤害提高，资源收益提高。
- 难度必须影响挑战，不应靠隐藏数值突然惩罚玩家。

## 8. 长期挑战

### 8.1 无尽演武

- 三人队伍连续应阵，每阵产生战报、评分、MVP 和军师建议。
- 十二种阵眼、八种战术阵法和八种协同可形成构筑。
- 九件遗物按里程碑永久解锁，同时保留单局取舍。
- 每三阵出现风险奇遇，自动续阵在奇遇处暂停，尊重玩家决定。
- 八种官军军势预告规则，如拒马、齐射、狼骑、连环、火油、雪夜、背水和封穴。
- 适合 5 至 15 分钟打一轮，也支持冲击个人最高波次。

### 8.2 星劫

- 六道风险规则按最高波次解锁。
- 玩家最多同启三道，每道都明确展示敌方增益和额外奖励。
- 风险必须改变打法，例如降低波间恢复、压制义气或提高敌方身法。
- 不要求用惩罚性失败换发现权，规则在出战前完全可见。

### 8.3 每周军令

- 每周固定种子、固定牌池和轮换目标。
- 所有玩家面对相同题面，但不要求实时联网排行。
- 周印提供三阶长期目标，过期记录归档而不是销毁。
- 错过后仍可继续普通演武和永久构筑。

### 8.4 战卷评鉴与战功

- 九回共二十七枚评鉴，来自无损、星命合击和速攻目标。
- 十九项永久战功覆盖主线、人物、命途、构筑、经营与挑战。
- 每项未解锁战功显示具体计数和进度条，避免模糊刷取。
- 奖励只结算一次，二周目继承档案和设置。

## 10. 美术与音频方向

### 10.1 视觉

- 基调：北宋末年、风雪、旧铜、青灰、墨黑和克制的朱砂红。
- 角色：电影感写实比例与戏剧化轮廓，避免把历史人物做成现代卡通宠物。
- 场景：黄河、汴京、野猪林、沧州、清风寨、江州、祝家庄、大名府、梁山泊各自有可辨认的环境母题。
- UI：金石、卷宗、军令与星图相结合，不使用无意义的霓虹和通用占位图标。
- 所有列表缩略图保持透明通道、脚底对齐和一致安全边距。

### 10.2 音频

- 十首 ComfyUI YuE2 循环主题，覆盖标题、江湖、聚义、清风寨、江州、普通战斗、首领、祝家庄、大名府与终卷。
- 十枚 Kenney CC0 战斗一次性音效，覆盖开战、刀击、重击、齐射、守御、闪避、恢复、终式、胜利与败北。
- 使用等功率交叉淡化、响度和真峰值检查，确保循环边界不爆音。
- 配乐与音效分别调音量，可一键关闭。
- 浏览器首次点击后解锁音频，避免自动播放策略导致无声故障。

### 10.3 资产管线

- 图像：ComfyUI + Qwen Image 2.1 / Qwen Image Edit。
- 视频：ComfyUI + MiniMax H3。
- 音乐：ComfyUI + YuE2 3B。
- 战斗音效：Kenney CC0 Impact Sounds、RPG Audio 与 UI Audio，本地裁切和母带衍生。
- 战斗特效：Kenney CC0 Particle Pack，由 Phaser 3 在运行时染色、缩放和缓动。
- 角色透明立绘使用前景分割并人工修整手、武器、边缘和裁切。
- 标题页从完整立绘生成 320px 透明 WebP 缩略图；正文与战斗继续使用高分辨率母版。
- 标题海报使用 116 KB WebP 运行时衍生图，避免重复下载 1.1 MB PNG。
- 运行时禁止调用 ComfyUI、模型端点或开发服务器。

## 11. 留存设计原则

### 11.1 允许的留存

- 清晰可见的下一步。
- 每场战斗都有构筑反馈。
- 新敌人规则倒逼换阵和换战法。
- 人物故事提供情感回报和唯一奖励。
- 短轮演武、长期图鉴和二周目共同承担回归动机。

### 11.2 不使用的留存

- 体力恢复锁。
- 每日签到连断惩罚。
- 抽卡重复角色和付费概率。
- 广告复活或看广告加奖励。
- 用随机低概率掉落拖延唯一内容。
- 为了日活强制玩家重复已通关的无关关卡。

## 12. 用户体验与无障碍

- 键盘、鼠标、触屏与标准 Gamepad API 覆盖主要流程。
- 设置提供标准、较大、最大三档字号。
- 设置提供减少动态和高对比界面，并尊重 `prefers-reduced-motion`。
- 支持声音总开关、配乐与音效独立音量。
- 支持自动战斗、四套战法、三档速度和演武自动续阵。
- 剧情有缓读、标准和快读三档文字节奏。
- 存档支持自动保存、手动保存、导出、导入、安全副本与旧档迁移。
- 设置页可直接查看隐私、EULA、支持、退款和第三方许可。

## 13. 技术交付

- Vite 静态构建，浏览器无需账号和服务器逻辑。
- Web App Manifest、安装图标和根作用域独立窗口模式。
- Service Worker 缓存应用外壳、发行文档与已加载的静态资产。
- 视频和字节范围媒体不写入离线缓存，避免大文件冲突。
- CSP、权限拒绝、来源限制和第三方许可进入自动门禁。
- 当前入口 JS 约 320.9 KB（gzip 99.9 KB），游戏数据独立块约 344.2 KB（gzip 111.7 KB），图标块约 22.6 KB（gzip 6.9 KB）；标题首屏图片约 365 KB。
- 浏览器生产站点约 136.18 MB、214 个文件；角色制作转身图、内部提示词清单、源图与 Source Map 不进入玩家包。
- 浏览器发行包同时生成逐文件 SHA-256、构建哈希、ZIP 校验和、缓存响应头与 Nginx 部署样例。
- 生产标题首屏实测总传输约 2.63 MB，包含 1.84 MB 五秒背景视频、116 KB 海报、脚本、样式和八张人物缩略图。

## 14. 验收标准

### 14.1 玩法

- 九回战役可从林冲一级新档连续通关。
- 三结局均能通过界面完成。
- 四十位好汉、二十八帖招贤和四十场列传均能解锁。
- 四种合击、四套自动战法、三档速度和自动续阵可实际推进战斗。
- 存档导出、导入、损坏拒绝、安全副本恢复与二周目继承通过。

### 14.2 视觉

- 1920、2560、3840、16:10、1280 和 390px 视口无横向溢出。
- 标题八人阵列无编号错位、图片拉伸、裁切或高分辨率立绘批量加载。
- 星图四十节点、评鉴标签、招贤卡、列传、演武 HUD 和设置页无重叠。
- 所有可见图片若使用 `object-fit: fill`，自然比例与渲染比例误差不得超过 2.5%。

### 14.3 自动化

- `npm test`：Unit 与内容完整性。
- `npm run test:e2e`：真实 Chromium 完整战役、挑战、存档、手柄和响应式回归。
- `npm run test:web`：生产构建、Manifest、Service Worker 与离线刷新。
- `npm run test:browsers`：Firefox 与 WebKit 的资产缩放、布局、倍速持久化、离线与减少动态回归。
- `npm run release:browser`：生成浏览器站点、ZIP、校验清单与部署配置。
- `npm run release:browser:verify`：逐文件验证发行包、PWA 资产、运行时角色资产与敏感文件排除规则。
- `npm run browser:preflight`：在内外部发行材料不完整时返回 `blocked`。
- `npm run verify`：脚本、Python、Swift、安全、音频、Steamworks、AI 披露和构建门禁。

## 15. 正式发行前剩余门禁

以下事项依赖外部账号、真实设备和法律信息，不能由代码测试替代：

- 真实 iOS 与 Android 设备最终回归。
- 发行主体、支持邮箱、地址、适用法律与退款政策人工审阅。
- Qwen、MiniMax、YuE2、ComfyUI 自定义节点和训练数据依赖的商用条款确认。
- Steam 正式 AI 内容调查提交。
- 若发行 Steam 版，补齐真实 AppID、DepotID、代码签名、商店后台和原生设备回执。

## 16. 后续扩展原则

- 新好汉必须同时带来一段独立冲突、一个可辨识战斗职责和至少一组构筑关系。
- 新章回必须改变地图、敌方规则或路线价值，不能只增加血量。
- 新演武内容优先增加题面和组合，不增加每日重复劳动。
- 新结局或大分支必须尊重已有角色动机，不为反转而反转。
- 所有新增资产继续保持来源记录、人工审核、等比缩放和浏览器体积预算。
