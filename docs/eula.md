# 《星命水浒》最终用户许可协议草案

生效日期：待发行主体确认

## 许可范围

发行方授予玩家一项非独占、不可转让的个人许可，用于在合法取得的设备上安装并游玩《星命水浒：风雪山神庙》。

## 限制

未经书面许可，不得：

- 出售、出租、再许可或商业分发游戏本体。
- 绕过游戏的技术保护、商店验证或访问控制。
- 以恶意方式修改客户端、破坏其他玩家体验或冒充官方版本。
- 移除游戏中的版权、商标与来源说明。

## 内容与虚构说明

游戏包含冷兵器战斗、流血、囚禁、冤案和权力压迫等主题。人物、事件与阵营表现属于戏剧化创作，不代表对现实群体或历史人物全部行为的评价。

## 本地存档

游戏默认把进度保存在玩家本机，并保留上一份有效安全副本。通过 Steam 启动且 Steam Cloud 可用时，游戏会将当前战卷同步到玩家自己的 Steam Cloud；本地与云端均有效时以最近保存时间为准。玩家导出的存档由玩家自行保管。正式发行前必须在商店页提供存档位置、备份方式和损坏恢复说明。

## 隐私

当前版本不包含广告或开发者遥测。Steam Achievements、Stats、Rich Presence 与 Steam Cloud 通过 Valve 的客户端服务提供；本地诊断日志不会自动上传。联网服务、外部崩溃上报或新的第三方 SDK 上线时，应同步更新隐私说明。

## 免责声明与责任限制

在适用法律允许的范围内，游戏按现状提供。发行方不保证游戏在所有硬件组合上无错误运行。责任限制条款必须由正式发行主体和适用地区法律顾问最终确认。

## 终止

玩家违反本协议时，许可可以终止。玩家仍可依当地法律保留不受限制的权利。
