# 星命水浒：风雪山神庙 1.0.3

1.0.3 将好汉阵容、个人剧情、长卷和人物素材扩展到 108 人，并完成旧存档迁移、军师荐阵性能优化与发行包验收。

## 108 位好汉

- 名册补齐 108 位可结义、可上阵好汉，姓名与绰号各自唯一；萧义、焦谦等新增人物拥有独立名号。
- 每位好汉均有电影感主视觉、透明战斗立绘、响应式缩略图和 1536×1024 三视角转身设定图。
- 108 张战斗立绘统一为 896×1024 RGBA 画布，记录透明轮廓和底部安全线，保留角色身高、武器与服装差异。
- 108 位好汉均有聚义招贤、三段个人异闻和一场终章列传；共 324 段个人剧情、108 场招贤与 108 场终章规则战。
- 新增东平府、大名府、揭阳镇、石碣村与浔阳江等人物旧路场景，让新增好汉的剧情和招贤发生在各自可辨认的地点。
- 好汉姓名、称号、异闻标题、终章目标、归阵选择与列传文案经过重复内容和通用占位文案检查。

## 完整长卷与人物档案

- 江湖长卷扩展为 28 回，从开卷、九回梁山主线延续至石碣受天文与全书终卷。
- 长卷入口、回目标题、场景背景与战斗数据一一对应，不再因回目标识复用而打开错误场景。
- 长卷网页入口展示 28 张回目卡与八个栏目导航，桌面、平板和手机视口均完成布局回归。
- 人物列传把本传、三段异闻、终章战意与归阵选择串成五段连续档案，已阅回目可在新周目继续查看。

## 存档迁移

- 存档版本升级至 28；1.0.0 至 1.0.2 的招募、名册、装备、营寨、演武、星命合击与结局数据继续兼容。
- 旧人物标识 `lehe`、`leihang` 自动迁移为 `yuehe`、`leiheng`，招募、阵型、命途与历练不会因改名丢失。
- 长卷已阅进度写入存档，并过滤无效回目标识；旧存档器物与新增好汉会获得当前版本默认配置。
- 迁移后的存档在继续游戏时立即回写，保存失败仍保留主存档与安全副本。

## 军师荐阵性能

- 108 位好汉的兄弟契改用二人与三人索引，避免每次推荐遍历完整契义列表。
- 每名好汉的攻击、治疗、控制、群体伤害与阵位特征预先计算；每个候选三人组只评估最佳阵位，不再穷举六种排列。
- 多元阵容改用固定容量插入排名，缓存签名覆盖名册顺序、装备、命途、考核、异闻领取、营寨建筑与难度，防止旧阵容被错误复用。
- 全阵容冷启动荐阵约 0.2 秒，相同构筑缓存命中约 0.1 毫秒；仅等级变化时复用排名，名册顺序变化会重新计算。

## 发行与资产

- `assets/manifest.json` 更新为 393 项运行时资产，其中 324 项记录 108 位好汉的主视觉、立绘与转身设定图。
- 运行时资产清单逐项记录尺寸、透明边界、字节数和 SHA-256；Steam 生成式 AI 披露同步更新为 108 位好汉的人物素材。
- 好汉制作目录包含 108 组、共 432 个角色文件；浏览器包仅包含 `keyart`、`cutout`、`thumb` 三套运行时资产，不包含制作转身图、内部生成提示词、源图与 Source Map。
- macOS 与 Windows x64 继续使用同一份生产构建；Windows 仅发布 x64 安装包与免安装 ZIP。

## 验证结果

- `npm test`：143 项测试通过，覆盖内容唯一性、108 人素材、324 段异闻、108 场招贤与列传、存档迁移和推荐性能。
- `npm run assets:verify`：393 项运行时资产全部可读取。
- `npm run steam:ai:verify`：生成式内容披露通过，运行时不含生成端点。
- 长卷、聚义帖网页入口、存档迁移、108 人布局、导航选中与浏览器兼容回归通过。
- `npm run verify`：JavaScript、Python、Swift 静态检查、发行安全加固、音频、Steamworks 与生产构建通过。
- `npm run release:browser:verify`、`npm run release:verify`：浏览器逐文件校验、桌面包内 `dist` 对比与平台 SHA-256 校验通过。

## 已知限制

- macOS ARM64 使用 ad-hoc 签名与 Hardened Runtime，没有 Apple Developer ID 签名和公证。
- Windows x64 安装包没有 Authenticode 证书，SmartScreen 可能提示未知发布者；下载后请核对发行页 SHA-256。
- 当前没有 Intel Mac 或 Windows ARM64 桌面包。

## 升级说明

1. 直接覆盖安装桌面版，或在浏览器中刷新等待 Service Worker 更新；无需重开新周目。
2. 旧存档首次读取时会自动迁移至版本 28，建议升级前在设置页导出一份 JSON 存档。
3. 新好汉会随对应回目的聚义帖逐步开放；已阅长卷和人物列传可在档案页继续阅读。
