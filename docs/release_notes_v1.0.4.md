# 星命水浒：风雪山神庙 1.0.4

1.0.4 精简主界面与首战引导，重做页面进入、点击、菜单和轻量粒子反馈，并加入开源的 Kenney CC0 界面音效与 UI 素材。现有 108 位好汉、108 人逐人剧情与角色素材、28 回完整长卷、存档迁移和 1.0.3 的角色阵容保持不变。

## 操作更直接

- 主菜单从八个入口精简为“行军 / 好汉 / 任务 / 营寨 / 更多”；当前次级页会在“更多”复核菜单中标明选中项。
- “长卷 / 演武 / 星图 / 设置”收进“更多”菜单，桌面与手机都保持一屏可操作。
- 标题页保留“续上旧卷 / 另开新卷 / 设置”和一个下一步目标入口。
- 异闻页先展示当前可接的招贤帖，已结义好汉的 108 人名册默认收起。
- 好汉传记与任务前情默认折叠，需查看时再展开。
- 第一场战役战斗只讲“路数克制 / 选招和目标 / 三路合击”三件事，确认“开战”后进入操作。
- 战斗日志默认收进“战况”，减少战斗画面中的常驻文字。

## 界面与动态

- 标题、地图、长卷、异闻、好汉、营寨、演武、设置与战斗面板统一使用更轻的进入过渡、明确的悬停与选中反馈。
- 主菜单、面板与首战引导使用 Kenney CC0 窗口边框和金色、白色星火素材，配合 CSS 动效保持清晰层级。
- 战斗特效按招式行为继续使用六类模板，并补充 Kenney 星火纹理；角色数值 HUD 保持在特效层之上。
- 设置中的“减少动态”和系统 `prefers-reduced-motion` 会关闭页面位移、粒子飞散与循环动画。
- 卡片、面板和菜单使用 4px 以内圆角，桌面、平板和手机视口不依赖横向滚动。

## 开源音效与素材

- 新增六个 CC0 界面一次性音效：点击、确认、打开、返回、错误和选择。
- 标题、五栏主菜单、更多菜单、异闻、首战引导、弹窗与战斗控制接入统一音效总线。
- 界面音效使用 44.1kHz 单声道 PCM WAV，经裁切静音边、归一与统一电平处理后进入游戏。
- 音效与配乐仍可独立控制音量，也可整体关闭声音。
- 素材来源、许可、处理方式与运行时路径记录在 [开源 UI 素材说明](open_source_ui_assets.md)，完整声明随游戏进入 `THIRD_PARTY_NOTICES.txt`。

## 持续验证

- 单元测试覆盖 108 位好汉、长卷、存档版本 28、推荐逻辑、开源界面音效映射与现有战斗规则。
- 浏览器回归覆盖标题、地图、更多菜单、长卷、异闻名册折叠、首战三动作、音效预载播放与桌面、手机横向溢出。
- Firefox 与 Playwright WebKit 生产构建兼容测试通过；390×844 手机视口可完整操作。
- 完整九回战役 E2E、自动战斗、标准 Gamepad、演武、奇遇、聚义帖、战斗 VFX 与页面滚动回归继续执行。
- `release:verify` 会逐文件比较桌面包内 `dist/` 与当前生产构建，避免旧界面或旧音效混入安装包。

## 升级与存档

- 存档版本保持 28，1.0.0 至 1.0.3 的招募、好汉、长卷、装备、营寨、演武、星命合击与结局数据可直接迁移。
- 首次打开新版时现有存档会照常读取，不需要重新开卷。
- 建议升级前从设置页导出 JSON 存档；损坏的导入文件不会覆盖本地有效存档。

## 发行包

GitHub `v1.0.4` 提供 macOS ARM64 的 DMG、ZIP，Windows x64 的 NSIS 安装包、ZIP，以及浏览器和本地分享 ZIP。安装包会重新打包当前 UI、开源音效、108 人素材与长卷，不复用 1.0.3 构建。下载后的 SHA-256 校验结果会在发布说明中补齐。
