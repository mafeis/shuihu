# 《星命水浒》无障碍说明

更新日期：2026-10-20

## 操作方式

- 键盘：`Space` / `Enter` 推进剧情，`Esc` 打开菜单，`A` 切换自动战斗，`T` 轮换自动战法，`1` / `2` / `4` 切换战斗速度，`C` 发动星命合击。
- 手柄：支持浏览器标准手柄映射；菜单使用十字键或左摇杆导航，确认键激活当前控件，战斗中用 `X` 切换自动战斗、`Y` 切换倍速、`LB / L1` 轮换战法。
- 鼠标与触屏：所有主要操作均提供可点击或可触摸控件。
- 自动战斗：可在设置中默认开启，也可在战斗中随时接管；均衡、破阵、守势与追残四套战法可用按钮或 `T` 键轮换。
- 战斗速度：支持 `1x`、`2x`、`4x`，减少重复操作等待。
- 演武自动续阵：战报停留后自动采纳军师建议进入下一阵；军中奇遇会暂停，玩家可随时关闭。
- 首战点拨：第一次进入战役战斗时只说明三条核心操作：路数克制、选招与目标、三路合击；确认“开战”后不再重复出现。
- 主菜单保留行军、好汉、任务、营寨、更多五个入口；长卷、演武、星图与设置可从“更多”打开。

## 视觉与动态

- 设置页提供“减少动态”，会关闭界面位移、闪烁与长时间动画。
- 设置页提供“高对比界面”，增强正文、边框、焦点与交互状态的明暗区分。
- 设置页提供“标准 / 较大 / 最大”三档界面字号，放大按钮、战斗信息与说明文字，不改变角色立绘比例。
- 游戏同时尊重系统的 `prefers-reduced-motion` 偏好。
- 关键按钮提供文字或图标双重提示，悬停图标会显示名称。
- “更多”菜单显示当前展开状态与所在次级页，打开时弱化背景内容，并可用返回键或手柄返回键关闭。
- 界面在 390px 至 4K 宽度下使用响应式布局，不依赖横向滚动完成主要流程。
- 角色、敌人、场景与 UI 资产保持原始宽高比，不使用破坏比例的强制填充。

## 听觉与文字

- 配乐与音效可以分别调整音量，也可以一键关闭全部声音。
- 剧情提供缓读、标准和快读三档文字节奏。
- 当前版本没有配音，因此不依赖听觉信息完成剧情选择。
- 战斗结果、奖励和错误提示使用文本提示，不只依赖颜色表达。
- 默认界面音效来自 Kenney CC0 素材集；设置页仍可独立调整音效音量或关闭声音。

## 存档与恢复

- 自动存档保留上一份安全副本。
- 设置页支持手动保存、导出与导入 JSON 存档。
- 旧版本存档会自动迁移；损坏存档不会覆盖已有的有效副本。
- 存档写入失败时游戏会显示可见错误提示。
- 桌面版会记录本地诊断日志；日志不会自动上传。

## 减少文字拥挤

- 标题、异闻、长卷、好汉、营寨与演武的辅助说明默认精简，较长的角色传记与任务前情收在可按需展开的区域。
- 第一场战役战斗只展示三条可执行操作，战斗日志默认收起，需要时点“战况”查看；展开与收起箭头在各尺寸下保持清晰。

## 已知限制

- 当前版本未提供完整屏幕阅读器语义树与全流程旁白。
- 战斗动画没有单独的“仅文本战斗日志”模式，但自动战斗可以降低操作负担。
- 尚未提供独立的色觉辅助配色预设。
- 正式发行前仍需在 Windows、macOS、Steam Deck 和常见手柄上进行原生无障碍回归。
