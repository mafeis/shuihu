# 《星命水浒》隐私说明

更新日期：2026-10-19

## 当前版本的数据处理

当前单机版本不要求注册账号，不包含广告、行为分析、遥测或内购。游戏运行时不向开发者自建服务器上传存档、设备信息或游玩数据。

游戏进度、设置、成就与演武纪录保存在玩家本机的应用存储中。玩家可以在设置页导出或导入 JSON 存档；导出文件由玩家自行保管。

通过 Steam 启动时，游戏可选择使用 Steam Achievements、Stats、Rich Presence 与 Steam Cloud。启用后，成就、统计与存档由 Valve 的 Steam 客户端处理，并受玩家 Steam 隐私设置和 Steam 服务条款约束。未由 Steam 启动、未配置真实 AppID 或客户端不可用时，游戏自动使用本地存档，不要求联网。

## 网络访问

正式游戏运行包只读取应用内的本地资源。项目中的 ComfyUI 服务仅用于开发阶段生成美术、音乐与战斗音效资产，不是玩家运行游戏时的组成部分。

## 崩溃与诊断

当前版本未启用自动崩溃上报，也没有开发者运营的远程诊断服务。桌面版会在本机应用数据目录写入轮转诊断日志，记录启动、资源加载失败、渲染故障与存档错误。日志不会自动上传，玩家可通过设置页打开日志目录并自行决定是否提供给支持人员。

## 联系与合规

正式发行前需要补充发行主体、支持邮箱、适用地区、数据控制者地址和适用法律，并在 Steamworks 后台启用 Cloud 与 Achievements 后完成最终一致性复核。本文件是当前实现的技术说明，不替代正式法律审查。
