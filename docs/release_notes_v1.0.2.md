# 星命水浒：风雪山神庙 1.0.2

1.0.2 是面向公测体验的稳定性、战斗表现与界面可读性更新。本次重点重做战斗技能特效与打击音效资产链，补齐推荐装备、多目标军师荐阵、紧凑营寨格点与多项移动端布局修复，并完成 1.0.1 之后合并到主线的一批演武、奖励页、名册和招募界面改进。

## 战斗表现与音效

- 战斗特效不再按刚、巧、谋、守四路循环播放同一段视频，改为按技能行为选择 `blade`、`volley`、`impact`、`guard`、`restore`、`ultimate` 六类通用模板。
- 技能分类会读取招式名称、描述、目标、治疗量、护御效果、攻击段数、义技标记与战斗事件；流派现在只负责调整色调和视觉气质。
- 刀枪突刺使用近战斩击层，箭矢飞石暗器使用齐射层，重兵器与范围攻击使用冲击层，格挡反击使用守御层，治疗净化使用恢复层，攻击义技与星命合击使用终式层。
- 特效由 DOM/CSS 图层实时绘制，包含冲击核心、双段震波、弧光、飞线、碎片、符印与光点；单次表现控制在约 0.6 至 1.2 秒，不依赖旧流派视频。
- `1x / 2x / 4x` 自动战斗会同步缩放特效计时，避免高倍速下旧特效残留、遮挡操作或拖慢回合。
- 好汉与敌人的数值 HUD 固定在特效层上方，立绘、光效和命中碎片不会盖住生命、义气、护甲与状态文字。
- 新增 10 枚可直接进游戏的战斗一次性音效：开战、刀击、重击、齐射、守御、闪避、恢复、终式、胜利与败北。
- 音效沿用 ComfyUI YuE2 资产流程生成短材质层，再由确定性瞬态层补足刀风、低频冲击、金属泛音、箭矢、治疗音与义技节奏，经过裁切、压缩、短淡出与母带处理后导出。
- 战斗音效统一为 44.1kHz 双声道、192kbps MP3，约 `-16 LUFS`，真峰值低于 `-1.0 dBTP`；运行时通过 `AudioBuffer` 预解码缓存播放，并保留 WebAudio 合成回退。
- 战斗技能提示、命中数字、状态变化、受击轮廓和镜头位移同步调整，减少只跳数字、没有动作反馈的情况。
- 多目标技能的命中位置、角色突进与返回、敌我站位和战斗指令面板重新整理，短屏和横屏下不再让立绘与按钮互相穿插。

## 界面与交互反馈

- 按钮、导航、货币变化、购买、领取与消耗操作增加统一点击反馈，反馈位置跟随实际指针，并限制在控件边界内。
- 顶部导航选中态改成更清晰的路数色与纸面高光组合，当前栏目在深色背景和战斗场景中都能辨认。
- 1440×900、1920×1080、1280×720 与 390×844 等分辨率重新审计，修复卡片横向滚动、文字裁切、底部导航遮挡、奖励按钮超出视口和锁定演武入口误显示。
- 战斗奖励页保留“继续下一章/返回路线”操作，长奖励列表会优先保证下一步按钮可见。
- 手机战斗指令栏恢复三列单行技能卡结构；好汉头像、技能名、消耗和冷却能够在约 390px 宽度内同时显示。
- 手机端 5 个技能（含终极技）可完整出现在战斗指令栏内，不再因技能消耗换行造成约 53px 的底部裁切。
- 战斗速度、自动战斗、均衡战法与技能选择仍可从顶部控制区操作，自动战斗开启后会隐藏不需要的技能列表，只保留当前行动提示。

## 名册、列传与招募

- 好汉页面工作台重新排版，列表与右侧详情分离，立绘、姓名、路数、等级、生命、义气与装备信息不再互相覆盖。
- 左侧好汉列表增加渐变遮罩和紧凑字号，长名称与数值不会直接叠在立绘亮部上；右侧大立绘保留不完整裁切，以叙事卡片的遮挡方式增强层次。
- 已结义好汉区域在移动端改为横向滚动卡片轨，避免把招募页或异闻页撑出横向滚动条。
- 聚义帖区域重新排版，招募条件、奖励、剧情入口和战斗按钮按内容优先级分组，长描述在窄屏自动换行。
- 斩将奖励页的入队好汉展示压缩为可滚动内容，结算页不会再因为新入队立绘、奖励列表和按钮同时出现而遮住姓名或确认操作。
- 群英列传、个人异闻与好汉详情的立绘采用 `object-fit: contain`、透明画布统一尺寸和底部安全线，避免拉伸、压扁或脚部被裁掉。
- 星图、名册与演武页的角色图片保持原始宽高比；动态数值、路数标签和长名称在桌面及手机视口中不会撑破卡片。

## 军师荐阵与推荐装备

- 军师推荐不再固定只给一套阵容，会根据“星命合击”“兄弟契”“稳健生存”“群体压制”等目标提供不同候选方案。
- 推荐阵容同时考虑三路合击、兄弟契、前后阵位、输出、群体招式、治疗与控制，不再为了单纯叠加护御放弃实际战力。
- 自动战法在满血时不会反复释放纯护御，会优先选择有效伤害；只有会补充义气或满足战术目标的辅助义技才会被保留。
- 自动战优先治疗生命最低的受伤队友，修复残局死循环、目标阵位为空导致技能无法选择、敌人无可施放招式导致回合卡住等问题。
- 新增推荐装备功能，按好汉路数、阵位、当前装备和战斗角色计算权重，给出更合适的兵刃、护甲与随身物组合。
- 推荐装备尊重唯一装备、已占用装备和不可用装备边界，不会把同一件装备重复分配给两名好汉。
- 装备页显示推荐理由、替换项、当前总评分与推荐后收益，玩家可以采纳推荐，也可以保留当前构筑。

## 营寨、演武与奖励

- 营寨从松散卡片列表重构为 5×4 紧凑格点布局；聚义厅、演武场、农田、矿场和林地占 2×2 格，星台、水产、石磨和厨房占 1×1 格。
- 建筑占地、等级、解锁条件、铜钱价格、当前库存与生产状态直接显示在营图上，建筑之间不会重叠或越出边界。
- 农田、矿场、林地和水产可采收小麦、铁矿、木材与鲜鱼；石磨把小麦加工为面粉，厨房把面粉加工为馒头。
- 营寨库存、建筑等级、生产链和营区扩建写入存档，升级版本时保留已建建筑、材料和好汉进度。
- 演武军势预告、战场 HUD、战后军功、S/A/B 战报、三选一军令、悬赏与奖励页重新排布，短视口下支持上下滚动。
- 修复演武奖励页某些分辨率无法滚动、遗物图标或军令信息显示不完整的问题。
- 星劫风险规则、按最高波次解锁、三道同时启用上限、演武失败恢复与跨重启续局继续兼容旧存档。

## 桌面、浏览器与存档

- 版本号升级为 `1.0.2`；当前存档版本仍为 27，兼容 1.0.1 及更早版本的招募、演武、装备、营寨、星命合击与结局归档数据。
- macOS 继续提供 Apple 芯片 ARM64 的 DMG 和 ZIP，使用显式 ad-hoc 签名、Hardened Runtime 与主程序/辅助进程权限配置；当前没有 Intel Mac 构建。
- Windows 只提供 x64 的 NSIS 安装包和免安装 ZIP，使用 SHA-256 与 RFC 3161 时间戳配置；当前包未使用 Authenticode 证书。1.0.2 起不再发布 Windows ARM64 产物。
- 浏览器发行包仍为根作用域 PWA，包含安装图标、Service Worker、离线外壳静态资源和四份发行法律文档。
- 本地分享包继续提供 `启动游戏.command`、`启动游戏.bat` 与 `启动游戏.js`，要求 Node.js 20 或更高版本。
- 桌面、浏览器和本地分享包均从同一份生产 `dist/` 构建，避免不同平台出现技能特效、音效或布局版本不一致。

## 资产与生成式内容披露

- `assets/manifest.json` 的运行时资产数量更新为 189 项，新增 10 项战斗一次性音效记录。
- 战斗音效保留 ComfyUI 原始材质、生成种子、处理脚本、最终哈希、采样率、码率和时长，便于后续复现与资产审计。
- Steam 生成式 AI 披露同步增加战斗音效，音频分类从 10 首循环配乐扩展为 10 首配乐加 10 枚战斗音效。
- 游戏运行时仍不会调用 ComfyUI、MiniMax、Qwen 或 YuE2，也不会把玩家存档、输入或设备信息发送给生成模型。

## 已知限制

- macOS 使用 ad-hoc 签名，没有 Apple Developer ID 签名与公证；首次打开需要右键应用选择“打开”，或在终端执行 `xattr -dr com.apple.quarantine "/Applications/星命水浒.app"`。
- Windows 安装包没有 Authenticode 证书，SmartScreen 可能显示未知发布者提示；下载后请核对发行页提供的 SHA-256。
- 当前没有 Intel Mac 构建，也没有经过真实 Steam AppID、实体手柄、真实 iOS/Android 设备或 Steam Deck 原生环境的最终回执。
- `npm run test:e2e` 在后续章节使用均衡自动战法时仍可能遇到随机战败超时；本次已用单元测试、运行态检查和完整 `npm run verify` 覆盖相关战斗规则，发布前应继续单独复跑完整战役回归。

## 升级说明

1. 桌面版直接覆盖安装即可，设置和存档会保留；如使用浏览器版，等待 Service Worker 更新后刷新页面。
2. 建议在大版本更新前从设置页导出一份 JSON 存档；导入损坏文件会被拒绝，主存档损坏时可使用安全副本恢复。
3. 首次进入 1.0.2 后，战斗特效、战斗音效、推荐装备和营寨数据会按当前资产清单重新载入；不需要重新开始新周目。
